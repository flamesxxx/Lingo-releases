# Lingo для Mac — альфа

Здесь находятся тестовые сборки Lingo и обновления для macOS. Исходный код
приложения в этом репозитории не публикуется.

[Скачать актуальную сборку](https://github.com/flamesxxx/Lingo-releases/releases/latest)

Нужен Mac с Apple Silicon (M1 или новее), macOS 26+, от 8 ГБ памяти.
Для базовой локальной модели — 3 ГБ свободного места плюс место для приложения
и DMG; первая загрузка около 1,1 ГБ, выполняется внутри Lingo.

## Установка

1. Скачайте DMG и перенесите Lingo в «Программы».
2. Откройте Lingo. Если macOS блокирует запуск: «Системные настройки» →
   «Конфиденциальность и безопасность» → «Всё равно открыть», затем подтвердите.
3. Пройдите знакомство и установите базовую модель кнопкой в приложении.

Это бесплатная тестовая поставка без Developer ID и нотарификации Apple.
Предупреждение macOS возможно. Не отключайте Gatekeeper и не используйте команды
для удаления quarantine. Если система сообщает о повреждении или вредоносном ПО,
остановитесь и свяжитесь с организатором тестирования.

## Следующие обновления

В меню Lingo выберите «Проверить обновления…», затем «Обновить» и подтвердите
перезапуск. Приложение само скачивает и проверяет новую версию перед установкой.
Фоновую проверку можно отключить в настройках. Установка происходит с вашего
подтверждения. Модели и настройки не переустанавливаются вместе с приложением.

Начиная с этой линии сборок используется постоянная подпись. При первом переходе
со старых ad-hoc сборок macOS может попросить повторно выдать разрешения. Дальше
подпись, bundle ID и путь установки сохраняются; фактическое сохранение разрешений
зависит от macOS и отдельно проверяется организатором.

Доступ к файлам публичный. «Альфа» означает стадию тестирования, а не ограничение
скачивания по паролю. Не отправляйте в публичные Issues личные тексты, ключи и
снимки экрана с персональными данными.
